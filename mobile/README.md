# SAQSHY AI

> **Жюри:** краткая проверка и запуск находятся в
> [JURY_QUICK_START.md](JURY_QUICK_START.md). Из чистого clone достаточно
> выполнить `npm ci --no-audit --no-fund`, затем `npm run verify`.

> Эта версия специально подготовлена для физического iPhone и Expo Go:
> **Expo SDK 54 / React Native 0.81.5**. Она устраняет ошибку
> `Project is incompatible with this version of Expo Go`, возникающую у SDK 57
> в переходный период.

Мобильный экологический инспектор Каспия: превращает фотографию нарушения в
проверяемый сигнал с предварительной AI-оценкой, координатами, временем и
SHA-256 паспортом доказательства.

Проект создан как отдельное нативное приложение на React Native + Expo. Это не
WebView и не мобильная версия сайта.

## Что уже работает в MVP

- эффектный мобильный onboarding и оригинальная иконка;
- нативная нижняя навигация, оптимизированная под управление одной рукой;
- камера и выбор изображения из галереи;
- предварительная классификация пяти типов экологических сигналов;
- оценка уровня риска и безопасные инструкции;
- геопозиция с корректным fallback на демонстрационную точку Актау;
- SHA-256 паспорт пакета доказательства;
- локальное сохранение обращений в AsyncStorage;
- появление нового сигнала на нативной GIS-карте;
- карта с фильтрами, зонами риска и карточками сигналов;
- экологический AI-ассистент с автономной базой знаний;
- подключаемый серверный AI без хранения секретного ключа в приложении;
- личный экологический вклад, миссии, достижения и системный Share;
- работа без регистрации и без обязательного интернет-соединения.

## Быстрый запуск через Expo Go

### Требования

- Node.js 22 LTS рекомендуется; поддерживается 20.19.4–24;
- npm 10+;
- актуальное приложение Expo Go из App Store;
- телефон и компьютер в одной Wi-Fi сети.

### Установка

Откройте папку проекта в VS Code, затем терминал PowerShell:

```powershell
npm ci --no-audit --no-fund
```

Запуск:

```powershell
npm run start:clear
```

На iPhone отсканируйте QR-код системной камерой и подтвердите открытие в Expo Go.

Если локальная сеть блокирует подключение:

```powershell
npm run start:tunnel
```

Для этого проекта не используется `npm run dev` и не нужен Vite. Команда
запуска - `npm start` или `npx expo start`.

## Как показать MVP жюри за 90 секунд

1. Пройти onboarding и показать главный индекс риска.
2. Открыть «Сканер» и выбрать тестовую фотографию из галереи.
3. Показать AI-классификацию, риск, безопасную рекомендацию и SHA-256 паспорт.
4. Нажать «Отправить сигнал» - приложение откроет карту с новым маркером.
5. Открыть SAQSHY AI и выбрать быстрый вопрос про нефтяную плёнку или тюленя.
6. Открыть «Вклад»: созданный сигнал сохранён локально, метрики обновлены.

## AI-режимы

По умолчанию работает автономный демонстрационный классификатор и экспертная
база знаний. Это честный offline fallback: MVP можно проверить без API-ключа и
без сервера.

Для подключения настоящей модели создайте `.env.local`:

```env
EXPO_PUBLIC_AI_API_URL=https://your-backend.example.com
```

Ожидаемый контракт сервера описан в [docs/AI_BACKEND_API.md](docs/AI_BACKEND_API.md).

Важно: ключ OpenAI, KazLLM или другого провайдера нельзя помещать в
`EXPO_PUBLIC_*` и в мобильный bundle. Секрет хранится только на backend.

## Проверка проекта

```powershell
npm run verify
```

Команда последовательно проверяет TypeScript, версии Expo-пакетов, выполняет
18 проверок Expo Doctor и собирает production iOS Metro bundle. Точно такой же
quality gate запускается автоматически в GitHub Actions на каждом push и pull
request: [`.github/workflows/validate.yml`](.github/workflows/validate.yml).

Отдельные команды:

```powershell
npm run typecheck
npm run expo:check
npm run doctor
npm run export:ios
npm run audit
```

## Если npm пишет ECONNRESET

Это обрыв соединения с npm registry, а не ошибка проекта.

```powershell
npm config set registry https://registry.npmjs.org/
npm config delete proxy
npm config delete https-proxy
npm cache verify
npm ci --no-audit --no-fund --fetch-retries=5 --fetch-timeout=300000
```

Если `npm ping` не возвращает `PONG`, отключите VPN или временно используйте
мобильную точку доступа.

## Производительность

- без WebView, UI рендерится нативными компонентами;
- нет Reanimated и тяжёлых анимационных библиотек;
- анимация сканирования использует только `transform` и native driver;
- маркеры карты не отслеживают повторные изменения (`tracksViewChanges=false`);
- карта не подписана на постоянный `onRegionChange`;
- сообщения AI виртуализированы через `FlatList`;
- карточки и строки сообщений мемоизированы;
- onboarding-изображение хранится в WebP и весит около 49 КБ;
- фотографии камеры сжимаются до quality 0.72 перед обработкой;
- все listeners, timers и animation loops имеют cleanup.

## Ограничения MVP

- offline-классификатор демонстрирует интеграционный pipeline и не является
  медицинской, лабораторной или юридической экспертизой;
- SHA-256 в MVP защищает цифровой пакет метаданных; production backend должен
  дополнительно хешировать исходные байты изображения;
- обращения сохраняются локально; production-версия синхронизирует их с API
  государственных органов и журналом аудита;
- демонстрационные сигналы на карте являются тестовыми, что разрешено ТЗ.

## Результат проверки зависимостей

`npm audit` возвращает **0 уязвимостей**. Для транзитивных зависимостей Expo
зафиксированы совместимые исправленные версии `postcss` и `uuid`; после этого
повторно пройдены Expo Doctor и production iOS export. Использовать
`npm audit fix --force` не нужно: эта команда может изменить major-версию Expo и
нарушить совместимость с Expo Go.
