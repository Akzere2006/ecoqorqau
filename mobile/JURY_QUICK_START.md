# SAQSHY AI — запуск для жюри

Проект готов к запуску из корня репозитория. Регистрация, `.env` и API-ключи
для проверки MVP не нужны.

## 1. Проверить репозиторий

Требуется Node.js 22 LTS и npm 10 или 11.

```bash
npm ci --no-audit --no-fund
npm run verify
```

Ожидаемый результат:

- TypeScript: 0 ошибок;
- Expo dependencies: совместимы;
- Expo Doctor: 18/18 checks passed;
- production iOS Metro bundle: создан без ошибок.

## 2. Открыть на iPhone

Установить актуальный Expo Go из App Store, затем выполнить:

```bash
npm run start:clear
```

Отсканировать QR-код системной камерой iPhone. Телефон и компьютер должны быть
в одной Wi-Fi сети.

Если локальная сеть блокирует соединение:

```bash
npm run start:tunnel
```

## 3. Демо-маршрут на 90 секунд

1. Пройти onboarding и показать индекс экологического риска.
2. В «Сканере» выбрать фотографию из галереи.
3. Показать AI-классификацию, риск, координаты и SHA-256 паспорт.
4. Отправить сигнал и открыть его новый маркер на карте.
5. Задать AI-ассистенту быстрый вопрос про нефтяную плёнку.
6. Открыть «Вклад» и показать сохранённый сигнал и обновлённые метрики.

## Важное

- Это нативный React Native + Expo проект, не WebView и не Vite-сайт.
- Версия зафиксирована на Expo SDK 54 для запуска в Expo Go на физическом
  iPhone в текущем переходном периоде Expo.
- Без backend приложение использует встроенный offline AI fallback, поэтому
  демонстрация не зависит от внешнего сервиса.
