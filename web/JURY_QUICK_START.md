# EcoQorgau — запуск для жюри

Проект запускается из корня репозитория без `.env`, регистрации и API-ключей.

## Проверка

Требуется Node.js 22 LTS и npm 10 или 11.

```bash
npm ci --no-audit --no-fund
npm run verify
```

Команда проверяет ESLint, TypeScript, production build, Worker artifact и
отрендеренный HTML.

## Запуск

```bash
npm run dev
```

Откройте адрес из терминала, обычно `http://localhost:5173`.

## Демо за 2 минуты

1. На «Обзоре» переключить Атлас, Рельеф и Спутник.
2. Нажать «Сообщить с берега», заполнить наблюдение и показать риск-скоринг.
3. Отправить сигнал и открыть его в журнале обращений.
4. В роли оператора назначить команду и изменить статус.
5. Переключиться в роль жителя и показать публичную историю.
6. Открыть аналитику и скачать CSV.

Интернет нужен только для онлайн-подложек карты. Интерфейс, демо-данные,
обращения и аналитика продолжают работать без них.
