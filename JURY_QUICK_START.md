# Проверка проекта жюри

## 1. Автоматическая проверка

```bash
npm ci --no-audit --no-fund
npm run verify
```

Ожидаемый результат: обе проверки завершаются с кодом `0`, Expo Doctor показывает `18/18`, а аудит зависимостей — `0 vulnerabilities`.

## 2. Web-демо EcoQorgau

```bash
npm run start:web
```

Маршрут на 2 минуты:

1. На обзоре изучить интерактивную карту Каспия и переключить слой карты.
2. Нажать «Сообщить», заполнить наблюдение и увидеть объяснимый риск-скоринг.
3. Отправить обращение, открыть его в реестре и изменить статус как оператор.
4. Переключить роль на «Житель» — служебные действия исчезнут.
5. Открыть аналитику и выгрузить CSV.

## 3. iPhone-демо SAQSHY AI

Во втором терминале:

```bash
npm run start:mobile
```

Отсканировать QR-код через актуальную Expo Go. В приложении показать onboarding, мобильную карту/сигналы, создание обращения и диалог с ИИ-помощником. При ограничениях локальной сети использовать `npm run start:mobile:tunnel`.

## 4. Структура решения

- `web/` — отдельный TypeScript PWA-проект;
- `mobile/` — отдельный TypeScript Expo iOS-проект;
- `.github/workflows/validate.yml` — независимая CI-проверка обоих продуктов;
- lock-файлы — воспроизводимые версии всех зависимостей.
